02 / SERVICES

What I do

Security work

Practical security assessments

Scoped, authorized testing to help identify and explain security weaknesses before they become incidents. Engagements are limited to explicitly approved assets and rules of engagement.

01 / EXTERNAL

Network & host testing

Review of approved IPs, domains, hosts, and network ranges.

02 / WEB + API

Web applications & API security review

Focused testing of web applications and REST, GraphQL, gRPC, or SOAP APIs within an agreed scope.

03 / CODE

Repository review

Security review of individual repositories or agreed organization scope.

04 / DIRECTORY

Active Directory assessment

Authorized review of Active Directory configuration, identity security, and common attack paths.

05 / MOBILE

Mobile application testing

iOS and Android assessment planning. Currently marked as work in progress.

06 / EXPOSURE

Exposure add-ons

Credential exposure checks, personal-data exposure checks, and typosquatting monitoring.

Engagement options

ONE-TIME

Focused penetration test

Deep, individually scoped audit with an executive report, vulnerability retesting, and security certificate.

ONGOING

Continuous security

Monthly option with continuous monitoring, weekly automated scans, and real-time alerting.
